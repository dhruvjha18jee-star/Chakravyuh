# Chakravyuh
Me and my team had built a game for the SAMYUTI ( INDIC GAME) event that happened in our college (Chanakya University) 
Theme B: The Chakravyuh (fast-paced survival
Basic Requirements:
The Vortex: A map featuring 3 to 5 concentric rings or walls that rotate, each with a small gap
to pass through.
Player Movement & Combat: A controllable player character that can move and attack enemies.
Stamina System: A mechanic where the player constantly loses health /stamina over time, which
can be restored by defeating enemies.
Win State: A clear condition for victory, such as reaching the center "Core" and surviving for a
set amount Of time
Later on I updated this file into a more modified sci-fi version
Enabled 8 directions, K/R-click = Repulse, Shift for speed but Voltage decreases faster
